# docs

Drop a `demo.gif` in this folder to fill the placeholder at the top of the main
[README](../README.md).

Good demo to capture:

1. A YASB bar visible over a Wallpaper Engine wallpaper.
2. Switch to a different, differently-colored wallpaper in Wallpaper Engine.
3. The bar (and taskbar, if you use TranslucentTB) re-tinting to match within ~1 second.

Keep it short (a few seconds, 2–3 wallpaper switches) and reasonably small so it loads
quickly on the GitHub page.
